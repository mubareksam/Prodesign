# Qelem 1.2 notes

This retrospective version follows historical commit `167ab2dc207b03fde53d524dd13902a928539b43`. It retains Qelem branding, the Qmer credit, the New canvas fix and the three-finger undo/four-finger redo gestures used in the rebranded 1.0 and 1.1 builds. The original historical 1.2 used two fingers for undo and three for redo.

New in 1.2: basic per-brush Studio controls, grid/isometric guides, symmetry assist, improvements to the stroke engine, FPS/onion/preview settings and optional silent MP4 export. MP4 requires a compatible WebView and the export is not verified on a physical Android device; playback settings are for preview and the MP4 records a forward loop. Grid/isometric guides do not snap strokes. These are basic implementations rather than full Procreate parity.

The package and stored project keys retain their original names for compatibility. As with earlier builds, the APK uses a public test certificate. Back up projects before updates or downgrades. Android normally refuses installing 1.2 over a higher version code, and uninstalling can delete artwork.
